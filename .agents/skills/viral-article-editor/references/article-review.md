# 文章编辑质检表

给每项打 0—2 分：0 = 不合格，1 = 一般，2 = 达标。总分 20 分。分数用于发现问题，不代表流量预测。

| 维度 | 检查问题 | 分数 |
|---|---|---|
| 选题 | 是否存在读者真实关心的矛盾，而非泛泛谈人生？ | /2 |
| 标题 | 是否具体、有张力，并且正文确实兑现？ | /2 |
| 开头 | 前 3 段是否尽快进入场景或核心冲突？ | /2 |
| 人话感 | 是否像一个有判断的人在说话，而非模板化总结？ | /2 |
| 具体性 | 是否有细节、案例、行为、成本，而不只是抽象词？ | /2 |
| 论证 | 结论是否由证据和推理支持？是否跳步？ | /2 |
| 反方 | 是否认真呈现了反对者的最强理由？ | /2 |
| 节奏 | 是否删掉重复观点、无意义小标题和空洞排比？ | /2 |
| 可信度 | 是否核实事实，避免虚构数据、案例和引语？ | /2 |
| 结尾 | 是否留下真实分歧，而不是硬性索要评论？ | /2 |

## 低分处理规则
- 选题或论证低于 2 分：先重做核心观点，不要只润色句子。
- 标题低于 2 分：重写标题，但不能夸大正文。
- 具体性低于 2 分：补充可验证案例或明确标注为假设场景。
- 反方低于 2 分：先写出反对者最合理的理由，再修正自己的结论。
- 可信度低于 2 分：核查、加限定或删除，不得靠语气掩盖证据不足。

## 发布后复盘
不要只看阅读量。若有数据，至少比较：
- 曝光到点击的转化（标题、封面）
- 完读率或阅读时长（正文节奏）
- 收藏与转发（实用性、可复用价值）
- 评论质量与争论点（观点是否击中真实分歧）

一次只改 1—2 个变量，否则很难判断什么真正有效。
