# 中文自媒体写作 Skill

本仓库用于维护个人中文自媒体长文写作流程。

## Skill
- `.agents/skills/viral-article-editor/SKILL.md`：长篇观点文章、社会观察、选题包装与编辑质检规则。

## 使用方式
该 Skill 适用于支持 Agent Skills / Codex 项目级 Skill 的环境。将仓库打开为工作区后，代理可根据 Skill 描述选择调用。把文件放在 GitHub 仓库里本身，不会自动把它安装到 ChatGPT 的所有普通对话中。

## 默认输出
标题（≤25字）+ 摘要（≤20字）+ 正文 + 5个标签 + 结尾讨论问题。
